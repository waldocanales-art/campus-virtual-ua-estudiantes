# Campus Virtual UA V2 — Portal del Estudiante

Prototipo navegable mobile-first/PWA.

## Incluye
- Mi proceso F1-F6
- Próxima acción y ruta personal
- Comunidad
- Documentos y observaciones
- Citas
- Perfil
- Asistente UA demostrativo
- Esquema Supabase
- Endpoint para n8n

## Ejecutar
```bash
npm install
npm run dev
```

## Producción
Antes de usar datos reales implementar autenticación institucional, RLS en Supabase, autorización por estudiante, firma de webhooks n8n y controles de privacidad.
